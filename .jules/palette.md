## 2025-04-01 - [Keyboard Shortcuts & Button Accessibility]
**Learning:** Adding `⌘/Ctrl + Enter` shortcuts to primary action inputs significantly speeds up the "capture" phase of note-taking. Combining this with descriptive `aria-label` and `title` attributes ensures the interface remains discoverable for power users and accessible for screen readers.
**Action:** Always include keyboard shortcut hints (e.g., '⌘/Ctrl+Enter') in the `title` tooltips for primary submission buttons to improve discoverability.
